# Изменения 4.1.0 Universal

Дата: 08.11.2026

## Совместимость и публикация
- Добавлены `.nojekyll` и GitHub Actions workflow для GitHub Pages.
- Все пути остаются относительными: приложение работает в подпапке репозитория.
- Убрана inline-регистрация Service Worker; добавлена CSP без `unsafe-inline` для скриптов.
- Добавлены fallback для `100vh`, `env(safe-area-inset-bottom)`, `structuredClone` и `Object.fromEntries`.
- Системные шрифты заменили не подключённые Manrope/Cormorant Garamond; мелкие подписи увеличены.

## Безопасность и данные
- Исправлен XSS в карточке истории: ID экранируются в `data-*`-атрибутах.
- Ужесточена проверка архивных записей: безопасный ID, тип и длина `positionDescription`, `spreadId`.
- Исправлена потеря новых записей: история хранится в порядке «новые первыми», лимит 2000 применяется к началу массива.
- Импорт больше не вытесняет существующую историю при достижении лимита.
- Шифрованный экспорт использует chunked Base64 и не падает на больших архивах.
- `createdAt` при отсутствии отображается как «дата не указана», а не `Invalid Date`.

## Контент и движок
- 56 Младших арканов переименованы в нормативную форму: «Туз Жезлов», «Король Пентаклей» и т. д.
- Все 17 combo-сочетаний теперь срабатывают; исправлены мёртвые имена.
- Предупреждения для «Семёрки Мечей» и «Девятки Мечей» снова работают.
- Исправлены грамматика `может/могут`, `карта/карты/карт`, `позиция/позиции/позиций`.
- Убраны дубли `..`, шаблонные повторы `positive`/`shadow`, исправлены «Стихия огня/воды/воздуха/земли» и «Масть Жезлов».
- 16 придворных карт переписаны без грамматических дефектов: корректные падежи в `relationships`, `work`, `obstacles`, `result`, `positive`, `shadow`.
- `relationship` и `distance` учитываются как романтический контекст; запрос о «изменениях» больше не трактуется как измена.
- Исправлен `followup-same` для отсутствующего расклада и сброс старого анализа при новом раскладе.
