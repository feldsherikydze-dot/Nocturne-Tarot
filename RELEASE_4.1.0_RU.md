# Релиз Nocturne Tarot 4.1.0 Universal

Дата: 08.11.2026

## Статус

Релизная сборка для публикации на GitHub Pages и локального запуска. Это статическое PWA без бэкенда, сетевых API и облачного ИИ.

## Состав релиза

- 78 карт: 22 Старших и 56 Младших арканов, только прямые положения.
- 10 раскладов с позициями и практическими вопросами.
- Локальный движок трактовки: позиция, сфера вопроса, масти, Старшие арканы, пары, предупреждения и контрсвидетельства.
- История до 2000 записей, избранное, заметки, сверка с реальностью и аналитика.
- Экспорт/импорт JSON, текстовая копия и зашифрованный архив AES-GCM/PBKDF2.
- Конструктор пользовательских раскладов до 10 позиций.
- PWA: `manifest.webmanifest`, Service Worker precache на 88 путей, работа в подпапке GitHub Pages.
- CSP без inline-скриптов; Service Worker регистрируется из `app.js`.
- 78 SVG-иллюстраций и иконки PWA.

## Установка

### GitHub Pages

1. Создайте публичный репозиторий и загрузите содержимое архива в ветку `main` или `master`.
2. В Settings → Pages выберите источник **GitHub Actions**.
3. Дождитесь выполнения workflow `.github/workflows/pages.yml`.
4. Откройте HTTPS-адрес. На iPhone: «Поделиться» → «На экран Домой».

### Локально

```bash
python3 -m http.server 8000
```

Откройте `http://127.0.0.1:8000`. Не открывайте `index.html` через `file://`: Service Worker и WebCrypto там не работают.

## Данные и приватность

- История, избранное и пользовательские расклады хранятся в `localStorage` браузера.
- Приложение не отправляет данные на сервер и не использует облачный ИИ.
- Экспорт JSON не зашифрован; зашифрованный экспорт использует WebCrypto. Пароль восстановить нельзя.
- Перед постоянным использованием проверьте сохранение, перезапуск и экспорт на своём устройстве.

## Известные ограничения

- Нет живого браузерного/iPhone-тестирования в среде сборки: CSP, Service Worker install и DOM проверены статически и через шимы.
- `localStorage` может очищаться системой или приватным режимом Safari.
- Автотесты проверяют структуру и регрессии, но не являются экспертной верификацией символических трактовок.

## Контрольные суммы

`SHA256SUMS` внутри архива содержит хеши файлов релиза. SHA-256 самого ZIP-архива лежит рядом с архивом в файле `Nocturne-Tarot-4.1.0.zip.sha256`.
