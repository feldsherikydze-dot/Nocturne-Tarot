# Nocturne Tarot 4.1.0 Universal

[![Tests](https://github.com/feldsherikydze-dot/Nocturne-Tarot/actions/workflows/tests.yml/badge.svg)](https://github.com/feldsherikydze-dot/Nocturne-Tarot/actions/workflows/tests.yml)

Локальное PWA для раскладов Таро: 78 карт, 10 раскладов, история, избранное, пользовательские схемы, экспорт/импорт и офлайн-режим. Приложение не обращается к облачному ИИ и не имеет бэкенда: трактовки считаются в браузере, данные хранятся в `localStorage` устройства.

**Живая версия:** https://feldsherikydze-dot.github.io/Nocturne-Tarot/

## Быстрый запуск

Не открывайте `index.html` через `file://`: Service Worker, WebCrypto и часть PWA-функций там не работают. Используйте HTTPS или локальный HTTP-сервер.

### GitHub Pages
1. Загрузите содержимое папки в публичный репозиторий GitHub, ветка `main` или `master`.
2. В Settings → Pages выберите источник **GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` опубликует статическую сборку.
4. Откройте выданный HTTPS-адрес. На iPhone страницу можно добавить на экран «Домой».

### Локально
```bash
python3 -m http.server 8000
```

Откройте `http://127.0.0.1:8000`. Для проверки офлайна один раз загрузите страницу, затем отключите сеть и обновите её.

Инструкция для полностью локального запуска на iPhone через a-Shell: `IPHONE_SETUP_RU.md`.

## Проверки

При наличии Node.js и Python 3:
```bash
node engine-tests.js
node sw-tests.js
node data-safety-tests.js
PYTHONIOENCODING=utf-8 python3 audit-cards.py
```

Ожидаемый результат: **117/117** проверок движка и интерфейса, **6/6** сценариев Service Worker, **14/14** проверок резервных копий и пользовательских схем, **78 карт, 0 ошибок, 0 предупреждений** структурного аудита.

Браузерные проверки — `tests.html`; открывайте по HTTPS или через `localhost`, не через `file://`.

Эти же проверки автоматически запускаются в GitHub Actions (`.github/workflows/tests.yml`) на каждый push и pull request.

## Что внутри

- 78 карт: 22 Старших и 56 Младших арканов; только прямые положения.
- 10 раскладов с позициями, вопросами и практическими ракурсами.
- Локальный движок трактовки: позиция, сфера вопроса, масти, Старшие арканы, пары и предупреждения.
- История до 2000 записей, избранное, заметки, сверка с реальностью и аналитика.
- Экспорт/импорт JSON, текстовая копия и зашифрованный архив AES-GCM/PBKDF2.
- Конструктор собственных раскладов до 10 позиций.
- PWA: Service Worker precache, manifest, работа в подпапке GitHub Pages.
- CSP без inline-скриптов; Service Worker регистрируется из `app.js`.

## Честные ограничения

- `file://` не даёт полноценный Service Worker/WebCrypto; для установки и офлайна нужен HTTPS или `localhost`.
- `localStorage` может очищаться системой или приватным режимом Safari. Регулярно экспортируйте архив и проверяйте сохранение на самом устройстве.
- Иллюстрации карт — авторские символические SVG, а не репродукции классических изображений Rider–Waite–Smith.
- Зашифрованный экспорт использует WebCrypto AES-GCM и PBKDF2; если браузер не предоставляет WebCrypto, функция не сработает. Пароль нельзя восстановить.
- Сочетания карт — объяснимые структурные правила, не «объективное предсказание». Качество формулировок следует оценивать как символическую интерпретацию.
- Автотесты не заменяют живой браузер: CSP, Service Worker install и DOM-события проверены статически и через шимы. Перед постоянным использованием пройдите расклад, сохранение, перезапуск и экспорт на своём устройстве.
