# Nocturne Tarot 4.2.0 — что изменилось

Дата сборки: 14.11.2026. Кэш Service Worker: `nocturne-tarot-v4.2.0-r4`.

## Экран трактовки

- Сверху — «Прямой ответ», затем карты и позиции. Матрица сочетаний, проверка прочтения, динамика, заметки и уточнения убраны в три закрытые секции `<details>`.
- Панель «Сохранить / Поделиться / Ещё» закреплена над нижней навигацией и остаётся доступной при прокрутке.
- В каждой карте раскрывается только «Тень, шаг и границы трактовки»; ссылка на библиотеку вынесена отдельно.
- Печать и PDF раскрывают все секции; интерактивные панели скрываются.
- Расклад сохраняется автоматически при открытии трактовки, кнопка обновляет запись.

## История, поиск и аналитика

- Записи сгруппированы по месяцам («ноябрь 2026»).
- Поиск показывает фрагмент найденной заметки, а не только совпадение по вопросу.
- Удаление записи и очистка истории обратимы: тост с кнопкой «Отменить» живёт 8 секунд.
- Импорт сначала сообщает число корректных записей, новых и дубликатов.
- Аналитика: полосы `progress`, подписи месяцев, компактные списки.
- В библиотеке поиск и фильтры закреплены сверху; подписи колоды увеличены до 10.5 px, элементы — не ниже 44 px.

## Карта дня и сохранность

- Карта дня одна на календарный день: повторное нажатие открывает уже сохранённую запись, а не тянет новую.
- На главной — виджет сегодняшней карты.
- Напоминание о резервной копии (нет копии / старше 30 дней) и индикатор заполнения `navigator.storage`.
- Создание обычной или шифрованной копии отмечается в журнале.
- Пароль шифрованной копии подтверждается вторым вводом.
- Синхронизация истории между вкладками через событие `storage`.

## Навигация и PWA

- Прямые адреса: `#home`, `#spreads`, `#history`, `#cards`, `#privacy`, `#analytics`, `#builder`, `#release`, `#card=<id>`.
- Системная кнопка «Назад» возвращает из карты в трактовку, из трактовки — в историю.
- При обновлении Service Worker появляется тост «Доступно обновление → Перезагрузить».
- Подсказка установки для iOS, манифест с `id`, `shortcuts` и реальными скриншотами 390×844.
- OG/Twitter-обложка 1200×630 (`assets/og-cover.png`).

## Контент

- Все 78 карт переведены на версию базы 4.2.0.
- Убраны шаблонные повторы: 6 вариантов финальной оговорки тени, 6 вариантов итога, 5 вариантов взаимности, 4 варианта роли, отдельные формулировки для мастей.
- Придворные карты получили отдельные границы интерпретации.

## Проверки

- `engine-tests.js` — 128/128, включая новые тесты покрытия `data-action`, хеш-навигации, аккордеонов, отмены удаления и манифеста.
- `sw-tests.js` — 6/6.
- `data-safety-tests.js` — 14/14.
- `audit-cards.py` — 78 карт, 0 ошибок, 0 предупреждений.
- Живой прогон: 0 ошибок консоли, back-цепочка «история → трактовка → карта → назад → назад», тост-отмена, карта дня без дублей.

## Что сознательно не делалось

- Облачный ИИ, аккаунты, бэкенд, CDN, внешние шрифты, светлая тема, перевёрнутые карты.
- Разбиение `app.js` на модули и переход на IndexedDB — вне задачи 4.2.0.
- Скриншоты 1080×1920: манифест использует реальные 390×844, чтобы размеры совпадали с файлами.
- Пережатие `icon-512.png` (356 КБ): без потери качества инструмента нет; файл не входит в precache.
- OG-обложка и скриншоты не прекешируются: они нужны сети при первом открытии, офлайн-ядро остаётся 86 файлов.
