## Ограничения

- Автотесты не заменяют живой браузер: CSP, Service Worker install и DOM-события проверяются только статически/через шимы.
- Node 8 не может разобрать современный синтаксис `app.js`; это ограничение тестовой среды, не браузера.
- Python 3.6 требует `PYTHONIOENCODING=utf-8`.
