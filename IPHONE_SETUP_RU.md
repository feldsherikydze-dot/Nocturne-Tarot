> **Рекомендуемый способ для универсального доступа:** опубликуйте папку через GitHub Pages (см. `README.md`) и откройте HTTPS-адрес. Тогда a-Shell и локальный сервер не нужны. Инструкция ниже остаётся для полностью локального запуска без публикации.

# Nocturne Tarot — запуск локально на iPhone

Этот способ не использует публичный сайт. Файлы остаются на iPhone, а приложение открывается в Safari через локальный адрес. Для этого используется бесплатный терминал a-Shell.

## 1. Установите a-Shell

Откройте App Store и установите **a-Shell**:
https://apps.apple.com/app/a-shell/id1473805438

## 2. Поместите папку проекта в a-Shell

1. В приложении «Файлы» скачайте архив проекта или скопируйте папку `Nocturne_Tarot_Local`.
2. Если скачали ZIP, нажмите на него, чтобы распаковать.
3. Откройте распакованную папку `Nocturne_Tarot_Local`.
4. Убедитесь, что внутри есть `index.html`, `app.js` и `styles.css`.
5. Переместите всю папку `Nocturne_Tarot_Local` в **На iPhone → a-Shell** в приложении «Файлы». Если папка a-Shell не отображается, сначала откройте a-Shell один раз, затем снова проверьте раздел «На iPhone».

## 3. Запустите локальный сервер

1. Откройте a-Shell.
2. Введите команды по одной, нажимая Return после каждой:

```sh
cd Nocturne_Tarot_Local
python3 -m http.server 8000 --bind 127.0.0.1
```

3. Оставьте a-Shell открытым. Сервер работает, пока команда выполняется; не закрывайте её и не завершайте процесс.

Если увидите сообщение, что порт занят, попробуйте порт 8080:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

## 4. Откройте приложение

1. Переключитесь в Safari.
2. Введите адрес `http://127.0.0.1:8000` и откройте его. Если использовали порт 8080, адрес будет `http://127.0.0.1:8080`.
3. Должна открыться страница Nocturne Tarot. Проверьте, что кнопки реагируют и расклад создаётся.

Адрес `127.0.0.1` означает сам iPhone; приложение не публикуется в интернете. Для работы страницы после первого запуска подключение к интернету не нужно.

## 5. Добавьте закладку на домашний экран

Когда приложение открыто в Safari:
1. Нажмите «Поделиться».
2. Выберите «На экран Домой».
3. Назовите ярлык `Nocturne Tarot` и нажмите «Добавить».

**Важно:** это ярлык на локальный адрес, а не самостоятельное нативное приложение. Сначала нужно запустить сервер в a-Shell. Если сервер остановился или iOS выгрузила a-Shell, сначала запустите команду снова.

## 6. Проверка функций

В приложении сделайте тестовый расклад, сохраните его в истории, затем перезагрузите страницу и проверьте историю. Также проверьте избранное и экспорт. Если история не сохраняется, сообщите, что именно происходит — поведение браузерного хранилища нужно проверить в конкретной версии iOS.

## Устранение неполадок

- **Safari не открывает адрес:** проверьте, что команда сервера всё ещё выполняется в a-Shell и папка содержит `index.html`.
- **404 или список файлов вместо приложения:** сервер запущен не в папке проекта. В a-Shell выполните `pwd` и `ls`, затем перейдите в папку, где лежит `index.html`.
- **Не открывается CSS/JavaScript:** проверьте наличие `app.js` и `styles.css` рядом с `index.html` и точное написание имён.
- **После перезапуска iPhone не работает ярлык:** откройте a-Shell и запустите сервер снова.

## Ограничения

- Это локальный веб-сервер внутри a-Shell, не отдельное приложение из App Store.
- iOS может приостанавливать приложение в фоне; непрерывная работа сервера не гарантируется.
- История хранится в браузере. Экспортируйте важные расклады и не очищайте данные Safari без резервной копии.
- Веб-страница и движок не заменяют полную редакторскую проверку всех трактовок Таро.
