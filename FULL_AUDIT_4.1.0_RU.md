## Что проверено статически

- Все 10 раскладов и их позиции проходят через `interpret()`.
- Все 78 карт интерпретируются в базовой позиции.
- Архивный валидатор отклоняет неизвестные карты, повторы, опасные ID и чрезмерные поля.
- История ограничивается 2000 записями без потери новых записей.
- Шифрованный экспорт использует PBKDF2-SHA256-250000 и AES-256-GCM.
- Относительные пути пригодны для GitHub Pages в подпапке.
- В приложении нет внешних CDN, шрифтов или сетевых запросов для загрузки данных.

## Не подтверждено в этой среде

- Нет браузера/Playwright, поэтому реальный DOM, Service Worker install и CSP не проверены в живом браузере.
- Нет физического iPhone/Safari: `structuredClone`, WebCrypto, clipboard, safe-area и офлайн проверяются только статически/через шимы.
- `node --check app.js` на Node 8 невозможен из-за современного синтаксиса (`?.`, `??`); для проверки использован Acorn 8.19.0. Это ограничение тестовой среды, не браузерной сборки.
- Python 3.6 требует `PYTHONIOENCODING=utf-8`; возможны нестабильные segfault при больших прогонах.

## Ручная проверка перед публикацией

1. Открыть GitHub Pages URL по HTTPS.
2. Пройти расклад, сохранить, перезагрузить страницу, открыть историю.
3. Проверить экспорт/импорт JSON и зашифрованной копии.
4. Отключить сеть после первого запуска и обновить страницу.
5. На iPhone добавить на экран «Домой» и проверить safe-area/поворот.
6. Проверить, что старые записи не исчезают после 2000 раскладов (или уменьшить лимит в тесте).
